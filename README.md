# One Star, Five Stars for the Food

An alien tourist's one-star review of planet Earth — written for make.fun's
"One Star, Five Stars for the Food" bounty.

> One star: your gravity ate my luggage, your people queue for bean water at dawn, but the tacos alone justify the 40-light-year trip.

Why it fits:

- **Alien voice** — the reviewer measures the trip in light-years, treats
  gravity as a luggage-eating hazard, and has no idea what coffee is
  ("bean water").
- **One-star grievance** — gravity, queues, dawn: a proper tourist complaint.
- **Food compliment** — the tacos alone justify a 40-light-year journey.
- **Fresh angle** — the review is not about the sights or the people; it is a
  logistics complaint from a being for whom Earth is a long-haul destination,
  redeemed entirely by one dish.

## Run it

```sh
node --experimental-strip-types main.ts
```

The program validates the sentence (1–200 characters, a single line, exactly
one sentence ending with a single period), then writes it to
`/output/entry.txt` as UTF-8 and reads it back to confirm it is byte-identical.
